## TL;DR for first-time setup
1. Activate the **Allied Properties** theme (registers Community post type + portal roles).
2. **Appearance → Customize** once to apply starter content (pages + menu), then Publish.
3. **Settings → Reading** → static homepage = Home.
4. **Settings → Permalinks** → "Post name" → Save.
5. Install **Contact Form 7** + **WP Mail SMTP** (forms/email) and **Members** (portal roles).
6. Add content, replace placeholder imagery, and run the deployment checklist.

## What to send me to finalize the design
The homepage **mockup** + exact palette/fonts (+ font files). Then it's a
token swap — see the mockup integration plan. No structural rework needed.
